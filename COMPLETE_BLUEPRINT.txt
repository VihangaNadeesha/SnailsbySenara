📊 DATABASE STRUCTURE
════════════════════════════════════════════════════════════════════════════

You'll have 6 tables:

PRODUCTS TABLE
├─ id: Unique product ID
├─ name: "Classic French", "Rosé Glaze", etc.
├─ description: Details about the product
├─ price: Rs. 2290, 2390, etc. (in paise)
├─ available_sizes: ["XS", "S", "M", "L"]
├─ inventory: Number in stock
└─ display_order: Sort order on website

PRODUCT_IMAGES TABLE
├─ id: Unique image ID
├─ product_id: Link to products table
├─ image_url: Path to image in cloud storage
└─ display_order: Which image to show first

ORDERS TABLE
├─ id: Unique order ID
├─ customer_name: "John Doe"
├─ customer_email: "john@example.com"
├─ customer_phone: "+91..."
├─ delivery_address: Full address
├─ order_status: "pending" → "paid" → "shipped"
└─ created_at: When order was placed

ORDER_ITEMS TABLE
├─ id: Unique item ID
├─ order_id: Link to orders table
├─ product_name: "Classic French"
├─ product_size: "M"
├─ quantity: 2
└─ unit_price: Rs. 2290

PAYMENT_SLIPS TABLE
├─ id: Unique payment ID
├─ order_id: Link to orders table
├─ file_path: Where slip stored in cloud
└─ verified_at: When admin verified

BUSINESS_SETTINGS TABLE
├─ bank_name: "ABC Bank"
├─ account_holder: "Senara"
├─ account_number: "XXXXX..."
├─ delivery_fee: Rs. 100
├─ whatsapp_number: "+91..."
└─ instagram_url: "https://instagram.com/..."
